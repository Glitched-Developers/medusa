# Медузка

Мобильное приложение с расписанием НИУ «БелГУ»: пары на неделю, аудитории,
напоминания, раздел взаимопомощи и профиль с достижениями.

Расписание берётся с сайта университета: <https://bsuedu.ru/bsu/education/schedule>.
Приложение не официальное — это удобная обёртка над открытым расписанием.

## Что умеет

**Расписание**
- Поиск по номеру группы, фамилии преподавателя или номеру аудитории.
- Неделя целиком, «сегодня» подсвечено; свайп/стрелки — другие недели.
  Если впереди пар нет, приложение само открывает следующую неделю.
- Тап по названию пары открывает курс на Pegasus (если преподаватель его
  подключил — регистрацию курс попросит сам).
- Тап по аудитории открывает расписание этой аудитории на неделю, с
  подписью группы у каждой пары.
- Избранное: группы, преподаватели и аудитории под рукой на стартовом экране.

**Без интернета**
- Расписание сохраняется на телефоне и открывается без сети, в том числе
  после выхода из приложения и повторного запуска.
- В настройках — срок хранения: неделя, месяц, три месяца или своё число
  дней (1–365). Когда сохранённый снимок показан, сверху висит честный
  баннер «Нет интернета — сохранённое расписание от 20.10, 20:28».

**Оповещения**
- Главный переключатель, напоминание за N минут до пары, уведомления об
  изменениях в расписании и о новых запросах помощи.
- Отдельный экран настроек и точный будильник там, где система разрешает.

**Помощь**
- Запросы помощи с лимитом участников (нельзя набрать больше, чем нужно),
  отклики, закрытие задач, свои задачи и статистика.
- Фильтр нецензурной лексики для всего, что публикует пользователь.

**Профиль и значки**
- Имя, роль, эмодзи-аватар, очки и уровни.
- 8 обычных значков за активность и 4 эксклюзивных по коду активации
  (`MEDUZA-DEV`, `MEDUZA-TEST`, `MEDUZA-FOUNDER`, `MEDUZA-NIGHT`).
- Витрина профиля: до пяти значков выбираются вручную; эксклюзивные
  переливаются — по окантовке бежит блик, вокруг пульсирует сияние.

**Обратная связь**
- Баг-репорт или пожелание прямо из приложения. Рядом с полем — честное
  предупреждение: вместе с обращением уходят модель телефона, версия
  Android, размер экрана и метка сборки. Больше ничего не собирается.
- Обращения хранятся в «Моих обращениях», их можно отправить (системное
  «Поделиться») или скопировать.

## Стек

Flutter (Dart 3.7+), Provider, `http` + `html` для разбора страниц расписания,
`shared_preferences` для локального хранения, `flutter_local_notifications` +
`timezone` для напоминаний, `device_info_plus` и `share_plus` для обращений,
`flex_color_scheme` для тем, собственные анимации (BorderBeam, RippleTap,
LightRays, BlurFade).

## Структура

```
lib/
  controllers/     состояние экранов и бизнес-логика
  services/        сеть (BSU), кеш, индексы групп и аудиторий, настройки
  repositories/    расписание: кеш → сеть → офлайн-снимок
  models/          расписание, профиль, значки, обращения
  view/screens/    экраны
  view/widgets/    карточки пар, значки, анимации
  themes/          светлая и тёмная темы БелГУ
```
`tool/serve_apk.dart` — локальная раздача собранного APK по Wi-Fi.

## Запуск

```bash
flutter pub get
flutter run --dart-define=APP_BUILD=dev
```

## Сборка

```bash
flutter build apk --release --no-tree-shake-icons \
  --android-skip-build-dependency-validation \
  --dart-define=APP_BUILD=20.10
```

`--no-tree-shake-icons` нужен, чтобы в релизе остались все иконки Material:
часть из них выбирается по названию значка во время работы.
Метка `APP_BUILD` показывается в настройках и уходит в баг-репорты.

## Тесты

```bash
flutter test
```

Покрыты: разбор расписания и недель, авто-переход на следующую неделю,
поиск групп и аудиторий, кеш и офлайн-режим, лимит участников задач, значки,
витрина профиля, обращения, фильтр лексики, анимация нажатий.
